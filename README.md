A deterministic Python program (Pillow) that draws a complete newspaper front page — "THE WORLD IN ONE DAY" — summing up the world news of Friday 20 November 2026 in a single 1024×1024 PNG: Russia's biggest barrage on Ukraine, with three Kyiv bridges hit and two missiles landing in Poland; Nvidia's 14% plunge on a reported SEC accounting probe as the Nasdaq erased all its 2026 gains; Britain and the EU agreeing deals to rebuild ties; GTA VI's record $2.36 billion first day; the Houthis threatening Saudi Red Sea ports; and a Van Gogh selling for a record $190.4m, plus a markets ticker. No network, no randomness: the same bytes on every run.

## Run it

```sh
pip install pillow
python3 main.py
```

Writes the entry image to /output/entry.png (or ./entry.png when /output does not exist).
